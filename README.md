# fruit-shop
# 🍓 Iman's Fruit Shop

A simple and interactive fruit shopping cart built using vanilla JavaScript, HTML, and CSS. Users can browse fruits, add them to the cart, manage quantities, choose currency, and simulate checkout with payment.

## 🌟 Features

- 🛍️ Product listing with images and prices
- 🛒 Add to cart, remove, increase/decrease quantity
- 💸 Checkout with simulated cash payment
- 🔁 Currency conversion (USD, EUR, YEN)
- 🧹 "Empty Cart" functionality
- 🎨 Clean and responsive UI with CSS animations

## 🚀 Getting Started

You can run this project locally or host it via GitHub Pages.

### ▶️ Live Demo
Once GitHub Pages is enabled:
```
https://<your-username>.github.io/fruit-shop/
```

### 🖥️ Local Setup

1. Clone the repository:
```bash
git clone https://github.com/<your-username>/fruit-shop.git
cd fruit-shop
```

2. Open `index.html` in your browser:
```bash
start index.html
```

(No server setup is needed since this is a static frontend app.)
